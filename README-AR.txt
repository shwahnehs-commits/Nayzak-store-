NAYZAK — متجر تجريبي ثابت
========================
1) افتح index.html محليًا لمعاينة المتجر.
2) لتعديل رقم واتساب: ابحث عن WHATSAPP_NUMBER في نهاية index.html.
   الرقم الحالي: 962786612798 (دون + أو مسافات، وفق تنسيق wa.me).
3) المنتجات التجريبية موجودة في مصفوفة productsData في JavaScript قرب نهاية الملف.
   لكل منتج: الاسم العربي/الإنجليزي، التصنيف، السعر بالدينار، المقاسات، ورابط الصورة.
4) استبدل صور المنتجات التجريبية بروابط صورك الحقيقية قبل الإطلاق.
5) الأسعار والمقاسات والمنتجات أمثلة وليست بيانات حقيقية للمحل.
6) نموذج الطلب يفتح رسالة WhatsApp جاهزة للمراجعة والإرسال. لا توجد قاعدة بيانات أو دفع إلكتروني أو لوحة مخزون.
7) للنشر المجاني، راجع خطوات GitHub Pages في الرد المرفق. ارفع index.html إلى جذر مستودع عام ثم Settings > Pages > Deploy from a branch > main > /(root) > Save.
